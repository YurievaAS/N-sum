# Подбор комбинации элементов под сумму N

Дан Excel-список `Наименование | Величина`. Нужно найти набор элементов, сумма
которых примерно равна N (с допустимой погрешностью только в плюс, по умолчанию 2%).

## Структура проекта

- `generate_test_data.py` — генерирует тестовый Excel (`data/input.xlsx`) с ~200 записями.
- `excel_reader.py` — читает Excel и конвертирует его в CSV (`data/input.csv`), а также читает CSV обратно.
- `algorithm.py` — сам алгоритм: динамическое программирование (0/1 knapsack на достижимость суммы),
  строит мапу `сумма -> элементы`, ограниченную диапазоном `[0; N*(1+eps/100)]`,
  и возвращает до 5 ближайших к N комбинаций (или пустой список, если ничего не найдено).
- `app.py` — Flask-веб-сервер: показывает текущий список, форму для N и погрешности,
  позволяет загрузить свой Excel-файл, вызывает `excel_reader` -> `algorithm` и выводит результат.
- `templates/index.html` — страница.

## Установка и запуск

```bash
pip install -r requirements.txt

# 1) сгенерировать тестовые данные (~200 записей)
python generate_test_data.py --count 200

# 2) запустить веб-приложение
python app.py
```

Открыть в браузере: http://localhost:5000

## Как это работает

1. При загрузке страницы читается `data/input.xlsx`, конвертируется в `data/input.csv`
   (модуль `excel_reader.py`) и отображается в таблице.
2. Пользователь вводит сумму `N` и (опционально) погрешность в % — она применяется
   только "в плюс": диапазон поиска — `[N; N * (1 + eps/100)]`.
3. `algorithm.py` строит DP-таблицу достижимых сумм в этом диапазоне, где для каждой
   достижимой суммы хранится путь для восстановления списка элементов. Из всех
   достижимых сумм выбираются до 5 самых близких к N (наименьшее превышение — самое
   "выгодное").
4. Если в диапазоне `[N; N*(1+eps/100)]` не нашлось ни одной достижимой суммы —
   выводится сообщение "нет подходящих комбинаций".

## Замена данных

Через веб-интерфейс можно загрузить свой `.xlsx`-файл с колонками
`Наименование` и `Величина` — он заменит текущий список (`data/input.xlsx`)
и автоматически будет переконвертирован в CSV.

Кнопка **«Обновить список»** отдельно от загрузки — она принудительно
перечитывает текущий `data/input.xlsx` заново, даже если он уже читался
раньше. Полезно, если файл на диске был перезаписан новой версией под тем же
именем (например, скриптом или вручную), — не нужно заново выбирать файл
через форму, достаточно нажать «Обновить список».

## Примечание о производительности

Алгоритм — точное ДП (аналог 0/1 knapsack), его сложность ~ `O(число_элементов × N)`
в масштабированных целых единицах. Для дробных величин значения масштабируются
до сотых (копейки), поэтому очень большие N с дробными величинами могут
увеличить время расчёта — для типичных сумм в диапазоне тысяч-сотен тысяч и
~200 элементов расчёт занимает доли секунды — единицы секунд.
